About Cryptography

HMAC

HMAC is a cryptographic technique that uses a secret key and a hash function to verify the authenticity and integrity of a message.

HMAC(K, m) = H((K ⊕ opad) ‖ H((K ⊕ ipad) ‖ m))

SHA-256

SHA-256 is a secure hashing algorithm that produces a 256-bit hash value.

Challenge–Response

The server sends a unique random challenge and the device proves that it knows the secret key without sending the secret key itself.

Security Features in this Project

  • Random challenges from Python's secrets module (OS secure random).
  • Constant-time comparison with hmac.compare_digest() stops timing attacks.
  • Replay protection: each challenge works once and expires after 2 minutes.
  • Keys encrypted at rest (Fernet/AES) and never sent to the browser.
  • Admin login with sessions, CSRF tokens and a lockout after repeated failures.
  • Two-factor authentication: a random 6-digit code emailed to the administrator, valid once for 10 minutes.
  • Rate-limited device authentication: a device is locked out for a minute after 5 failed attempts.
  • Key custody: the master key can be split into shares (Shamir) and the vault sealed, so no single person or file holds it.
  • Full audit trail of every success and failure.

How Secure Is This, Really?

Device keys: 2²⁵⁶ possibilities

Even at 10¹⁸ guesses per second — far beyond any real hardware — brute-forcing a 256-bit key would take roughly 10⁴¹ times the current age of the universe. Rate limiting adds nothing to this; the math already makes it infeasible.

The 6-digit login code: a different story

An emailed code has only 10⁶ possibilities. Without a lockout, a computer could try all of them in well under a second. That is exactly why the login locks out after 5 failed attempts, why a code stops working after 5 wrong guesses of its own, and why it expires after 10 minutes either way.

Without the key, an attacker can...

Cannot: forge a valid HMAC, replay an old response, or recover a key from a stolen database. Can: see that a device ID exists, and send guesses — which are now rate-limited and logged. See the README's "Security Analysis" section for the numbers.
